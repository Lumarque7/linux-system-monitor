Linux System Monitor
A lightweight Python-based monitoring tool developed on Ubuntu Server as part of a practical Cloud and DevOps Engineering portfolio.

Features
Display the server hostname and current date.

Monitor system uptime and load averages.

Display memory usage and availability.

Monitor disk space usage.

Execute Linux system commands automatically using Python.

Technologies
Ubuntu Server 22.04 LTS

Python 3

Linux CLI

Git

Installation and Usage
Clone the repository and navigate to the project directory.

Run the monitoring script:

python3 system_monitor.py
